# 首站现场点位映射表（空白模板）

> 用于把现场 PLC/仪表读数映射到小禹的平台点位编码。下表的平台编码来自当前仓库的站点模板，仅用于对照；**PLC 地址、协议、数据类型、倍率和枚举值必须由试点站现场核实后填写**。未核实的点位不要接入告警规则，也不要把演示值当作实测值。

建议先选择 3 个低风险只读点位做首轮联调：进水液位、提升泵运行状态、BAF 溶解氧。设备运行/故障状态只读取 PLC 已公开的状态寄存器，不做任何写入。

## 填写和验收约定

1. 记录原始寄存器读值与仪表本地显示值，确认倍率、偏移、字节序、单位换算后再填入上送 JSON。
2. 对运行状态、故障位和反冲洗阶段，写清楚每个数值/位的含义；不得凭设备名称推断编码。
3. 每个点位至少完成一次“现场显示值—网关解码值—平台显示值”三方对照，并记录误差和时间戳。
4. 先只读接入和观察；确认数据稳定后再启用告警。平台云端不向 PLC 写寄存器，也不控制单机处理流程。
5. 如果平台没有现场实际点位，应先补建/校正点位档案，再接入；不要为了通过接口校验而复用语义不符的编码。
